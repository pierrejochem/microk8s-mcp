Type: Barlow Condensed — SemiBold for the wordmark, Regular for the descriptor line.
Both lockups ship the type as outlined paths, so they render identically without the
font installed; edit the wordmark by re-setting it in Barlow Condensed and re-outlining.
Barlow is (c) The Barlow Project Authors, SIL Open Font License 1.1.

Clear space: one cell width (8 grid units) on all sides.
Minimum size: 24px for the mark; below 32px drop the lower cell and keep the micro sign.
